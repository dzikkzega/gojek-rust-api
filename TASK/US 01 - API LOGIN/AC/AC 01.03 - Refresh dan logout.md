# AC 01.03 — Refresh dan logout

**Project:** GOJEK-rust-api  
**User Story:** [US 01 — API LOGIN](../US.md)  
**Status:** Done (Docker verification)  
**Priority:** P0 — MVP

## Acceptance Criteria

Refresh token aktif digunakan → token baru diterbitkan dan lama dicabut; pemakaian ulang (replay) refresh token yang sudah dicabut mencabut seluruh sesi aktif user dan mengembalikan `409`; maksimal 8 sesi aktif per akun; logout mencabut sesi sehingga token tak dapat dipakai lagi.

## Done when

- Kriteria terpenuhi dan diuji.
- Error dan otorisasi konsisten dengan [PRD](../../../PRD.md).
- Tidak ada rahasia atau data sensitif di log.
