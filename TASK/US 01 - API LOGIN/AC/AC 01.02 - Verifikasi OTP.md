# AC 01.02 — Verifikasi OTP

**Project:** GOJEK-rust-api  
**User Story:** [US 01 — API LOGIN](../US.md)  
**Status:** Done (local Mailpit)  
**Priority:** P0 — MVP

## Acceptance Criteria

Kode OTP aktif yang dikirim ke email dan diverifikasi dengan benar → API membuat/menemukan akun berdasarkan `email_normalized`, menandai email terverifikasi, dan membuat sesi; kode salah, kedaluwarsa, terkunci, atau terpakai ditolak.

## Done when

- Kriteria terpenuhi dan diuji.
- Error dan otorisasi konsisten dengan [PRD](../../../PRD.md).
- Tidak ada rahasia atau data sensitif di log.
